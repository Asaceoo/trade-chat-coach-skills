# 多语言外贸跟进话术包（俄 / 西 / 阿 / 法 / 德 / 葡）

配套 `SKILL.md` 使用。**适用**：客户说俄语、西班牙语、阿拉伯语、法语、德语、葡萄牙语时，用本包的短句开场和跟进；分析仍用中文。

## 0 使用纪律（先读，违反会翻车）

1. **这些是"起步短句"，不是合同语言。** 价格、交期、付款、认证等**关键条款**用本包短句发出后，必须让客户用他的语言明确确认，或用翻译工具 + 同事复核再发正式文件。**宁可慢，不要错。**
2. **不假装流利。** 用客户语言写短句是尊重，写长文装流利是灾难。每封信控制在 5 句以内，复杂内容回到英文（外贸通用语）："For the full details, may I send this in English?"——客户都会接受。
3. **正式文件（PI/合同/邮件长文）默认英文**，附一句客户语言的说明即可。
4. **文化雷区表（第 3 节）先看**——尤其阿拉伯语的斋月/周五、俄语的称呼习惯。

## 2 万能三句（任何语言都够用的骨架）

1. 开场 + 感谢：`[你好]，感谢您的[询盘/邮件/消息]`（各语言见上表）
2. 一个需要确认的问题：`请确认：[数量/规格/目的港]`（挑一个，别一次问三个）
3. 下一步承诺：`我会在 [时间] 前给您 [报价/PI/方案]`（可用英文写数字和时间）

> 三句话就能撑起一次高质量跟进。长篇的翻译成本高、出错率高，不如三句话 + 附件。

## 3 文化雷区表

| 地区 | 雷区 | 处理 |
|---|---|---|
| 中东/北非 | **周五休息**；**斋月**期间白天工作节奏慢 | 周五/斋月白天不催单；斋月问候"Ramadan Kareem"（رمضان كريم）加分 |
| 阿拉伯语 | 宗教用语（"愿主赐福"）不懂别乱用 | 用中性商务用语即可；不要用宗教套近乎 |
| 俄罗斯/独联体 | 习惯正式称呼"先生/女士"（господин/госпожа）+ 姓氏；称名带父称是亲近信号 | 首次接触用正式称呼；对方先放松再放松 |
| 拉美西语 | 西班牙西语（vosotros/ustedes）与拉美有差异；巴西人看重关系与耐心 | 跟巴西客户用 PT-BR 而非欧葡；先建关系再谈细节 |
| 德国 | 重精确、直接、文件规范 | 承诺的交期必须兑现；文件用德语或英文但必须工整 |
| 法国 | 重视礼貌框架（bonjour 开头、merci 收尾） | 少一句礼貌语都会被感知为粗鲁 |

## 4 与翻译工具配合的流程（推荐工作流）

1. 用本包短句起草（安全）；
2. 重要内容（价格/交期/付款）**用翻译工具逐句核对**，或发给公司里会该语言/用翻译服务的同事复核；
3. 发出后请客户用他的语言确认关键数字（"请确认价格 [X] 和交期 [Y] 是否正确"——英文亦可，客户都懂）；
4. 把客户母语的确认原文存档（作为往来证据）。

> **为什么不能全靠机器翻译发长文**：机器翻译的长信在商务场景错一个数字/一个条款就是事故；短句 + 确认闭环，风险可控且专业感反而更强。
