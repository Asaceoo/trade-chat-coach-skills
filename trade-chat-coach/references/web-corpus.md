## 1 22 个主题的已验证要点

### 1.1 压价（客户说价格太高）
- **"76% 的客户觉得报价/方案本身不足"** [B]——客户喊贵，先自查报价完整度（信息错乱、拼写错误、缺价值展示），再谈价格。[来源：caftp.com/news/info/1369]
- 新人典型错误：客户喊贵就急着降价/给折扣；正确动作是**用提问深挖需求**，区分"真贵"和"习惯性砍价"。[来源：zhuanlan.zhihu.com/p/28267291]
- 中高档市场质量路线话术："价格重要，但把维护+服务的附加价值算进去，我们更便宜。"[同上]
- **印证**：`negotiation.md`（不主动降价、换条件）、`signals.md`（压价是流程动作）。

### 1.2 收款与催款（★ 技能新增层）
- **"款到即发"话术**："好消息，您的货已全部完成并通过质检，随时可发货。现在只等尾款到账，一收到就立即安排出运，保证您按时收到。"——不要说"请您尽快付款"这种软话。[来源：52wmb.com/new/900]
- **分期付款话术**（客户说没钱）："我理解您的资金压力，做生意都会遇到。如果一次性付款困难，可以先付 50%，剩下 50% 分两周结清。"——给方案，但时间/金额要设限。[同上]
- **老客户拖账感情牌**："我们合作这么久一直很愉快，也感谢您的信任。不过这笔尾款财务催了好几次了，能否请您安排一下？不然可能影响后续合作。"——**把催款责任推给财务，不是你个人在催债**。[同上]
- **两条铁律**：钱没到账货绝对不能出；说 30% 定金就是 30%，不妥协成 20%；付款条件全写进合同。[同上]
- **印证/补充**：`templates.md` 有催单模板，但缺"收款/催款"话术层——**这是本语料对技能的最大新增**。

### 1.3 已读不回（按场景拆模板，不只是时间轴）
- **报价后 1-3 天**：强调报价优势 + "我们提供私人定制、可免费寄样；订单量大可给更优惠价格"。[来源：sourcingfairs.com/news.html?id=486]
- **产品资料后**："资料您收到了吧？产品细节、规格有疑问随时联系我。"[同上]
- **样品发出后**："样品应已送达，您对质量、性能有什么反馈请告知，这对我们后续合作很重要。"[同上]
- **真实时间锚**："近期原材料价格波动，此报价有效期有限，建议尽快决策。"[同上]
- **印证**：`zh-playbook.md#S3` / `playbook.md#S3`、`templates.md`——语料证实"已读不回要分场景给模板"，比纯时间轴更细。

### 1.4 开发信
- **避免垃圾邮件关键词**："100% free"、"click here" 等易进垃圾箱。[来源：xiaoman.cn/article/695]
- 标题用**数字+客户姓名**提高打开率；发送前调研客户痛点做个性化。[同上]
- 结尾明确行动号召（祈使句/问句）。[同上]
- **低回复率不是单一文案问题**：客户匹配、内容、发送方式、后续跟进共同决定。[来源：zoho.com.cn]
- **印证**：`eq-communication.md`（"给新信息才有回复理由"）。

### 1.5 异议处理
- **"90% 的跟进失败不是客户没需求，而是异议处理方式不对"** [C/经验共识]。[来源：jiandaoyun.com]
- 先**情感认同**，再处理异议（印证 LAER 第一步）。[来源：woshipm.com]
- **反向激发回复欲**："刘总，您一直没回复，我猜可能是方案还不够匹配。方便告诉我您的顾虑吗？我立刻调整。"[同上]
- **好话术公式**："50% 痛点挖掘 + 30% 信任建立 + 20% 紧迫推动"。每单成交后记录有效话术。[同上]
- **印证**：`objections.md`（LAER/3F/ARC 模型）。

### 1.6 老客户复购
- **时间分配**（经验值，非精确统计，三项须合计 100%）："约 70% 精力跟进维护老客户，20% 寄样/在谈，10% 开发新客户。" [B/经验共识，有前提条件][来源：zoho.com.cn/crm/articles]
- 按客户类型（潜在/意向/老客户）分类跟进，不做"一刀切"。[同上]
- **印证**：`framework.md` 第 6 节精力分配 **P1/P2/P3**（⚠️ 注意：**"数据分级 A/B/C"** 是另一套体系，
  用于标注证据可靠性；**客户分层一律用 P1/P2/P3**，两者不可混用）。

### 1.7 价格谈判
- **"93% 的客户第一次报价后会要求降价，但最终成交的订单中只有 37% 真正降价超过 5%"** [B/2024 外贸行业数据，机构来源 XTransfer]。[来源：xtransfer.cn/c/ByZpve]
- **对等让步**："在一个地方让步，就要求客户在另一个地方让步，取得平衡。"（常见操作：让价换加量）[来源：xtransfer.cn]
- 反例："我们的产品质量很好" → 客户反问"好在哪里？" → 哑口无言——**价值必须具体化**。[来源：zhida.zhihu.com 问答]
- **印证**：`negotiation.md`（让步阶梯、BATNA、反锚定）。

### 1.8 电话开发
- **核心原则：永远不要只报价格，同步塑造价值。** 客户说 "Your price is too high"，别直接 "Okay, how about a discount?"。[来源：xiaoman.cn/article/858]
- **Feature → Benefit 转化**："我们用了 XXX 材料，所以你的客户退货率会降低 15%"。[同上]
- 惨痛反例（日本客户）：第三封邮件就用"美式紧迫感"话术 → 客户永久失联；**对保守/重关系的文化，压迫感话术是冒犯**。[同上]
- 德国工程师客户："I need to discuss with my team" 拖三个月——需要共情+证据，不是施压。[同上]
- **印证/补充**：`templates.md` 电话脚本 + `i18n-phrases.md` 文化雷区（日本/德国案例直接印证）。

### 1.9 破冰与信任
- 专业度分"内部+外部"，**能帮客户解决问题就能快速建立信任**。[来源：zhuanlan.zhihu.com/p/662122064]
- 能力不足时**明说并推荐别的选择**——诚实反而加分。[同上]
- **印证**：`eq-communication.md`（诚实是信任资产）。

### 1.10 成交信号与逼单
- **"整个业务过程就是一个'逼'的过程，逼需要技巧，不能操之过急。"** [来源：globalso.com]
- 17 个逼单技巧 / 10 个逼单技巧的常见归类：给选择、限时、假设成交、换条件、临门一脚前先解决最后一个异议。[来源：xtransfer.cn / b2b3.com]
- **印证**：`objections.md` 成交推进（二选一、假设成交、换条件收口）。

### 1.11 邮件营销（第二轮新增）
- **行业基准**：B2B 平均打开率约 **21.33%**、点击率 2.62%；掌握方法的企业可到 **40%+/10%+** [B/行业统计]。[来源：zhuanlan.zhihu.com/p/1960637263470893013]
- 主题行：移动端**30-50 字符**；写"具体价值"（"新产品可降低您 30% 生产成本"）而非宽泛介绍；数字增强可信度。[来源：xiaoman.cn/article/743]
- 正文逻辑：**问题识别 → 解决方案 → 价值证明 → 行动呼吁**；前三行决定是否继续读。[同上]
- 发送时机：美国客户**周二至周四上午 10-14 点（EST）**，避开感恩节/圣诞。[来源：topease.net]
- 图片文字比 30:70、加 alt 标签，防垃圾过滤器。[同上]
- **印证/补充**：`templates.md`（邮件模板）+ `eq-communication.md`（个性化=把他放心上）。

### 1.12 展会英语（第二轮新增）
- 开场白要**专业、简洁、带温度**；第一印象决定客户是否愿意继续聊。[来源：zhuanlan.zhihu.com/p/1982806751674925209]
- "比 Happy Monday 好得多的邮件/开场白"方向：具体到客户业务，而非泛泛问候。[来源：m.cifnews.com/article/74948]
- **印证/补充**：`i18n-phrases.md`（六语言开场短句）+ `zh-playbook.md#S12` / `playbook.md#S12`。

### 1.13 跨境客户维护 / 私域（第二轮新增）
- **"得私域者得天下"**：WhatsApp 等即时工具把流量"私有化"，所有触达线索无论成交与否都沉淀为可再触达资产。[来源：cm.com/zh-cn]
- Forrester：**68% 购物者更愿选择提供实时沟通的品牌；81% 体验过智能客服的消费者会再次购买** [B]。[同上]
- 从首购到复购决策期长，关键是**合理频率 + 个性化内容**。[同上]
- **印证/补充**：`framework.md` 精力分配（老客户维护权重高）。

### 1.14 跟单流程（第二轮新增）
- 标准闭环：**订单接收（核实规格/数量/价格/交期）→ 跟进付款 → 跟踪生产 → 质量控制 → 协调沟通 → 文档管理**。[来源：ipaylinks.com]
- 付款按合同跟进、质检不代签、异常及时协调——跟单的本质是"不让任何一个环节静默"。[同上]
- **印证/补充**：`templates.md`（PI/延误通知模板正是跟单环节的沟通件）。

### 1.15 谈判场景准备（第二轮新增）
- 新手高频 5 场景：**破冰 / 价格 / 交货期 / 质量纠纷 / 收尾**。[来源：cnabke.com]
- 谈判前备好证据包：产品资料、公司资质、**案例分析**、市场调研报告——用证据支持主张。[来源：fumasoft.com]
- **印证**：`negotiation.md`（BATNA/客观标准：证据就是客观标准）。

### 1.16 售后与客服（第二轮新增）
- 跨境电商客服要**"母语思维"**：懂当地消费习惯、节日礼仪、沟通潜规则，而不是语言翻译。[来源：getechlaw.com.cn]
- 全渠道统一后台，投诉响应一致性。[同上]
- **印证/补充**：`eq-communication.md`（情绪标注只在母语有效，PNAS 实证）+ `i18n-phrases.md` 文化雷区。

### 1.17 海关数据开发客户（第三轮新增）
- 先明确产品英文名/规格/应用场景，用 **HS 编码**（"国际贸易身份证"）定位，不同国家叫法不同。[来源：zhuanlan.zhihu.com/p/1956031374030008535]
- **输同行公司名查其出口客户分布** → 发现潜在客户/市场空白；看数据价格判断同行报价区间，避免盲目低价。[来源：xtransfer.cn/c/NvkoYB]
- 开发信**提及海关数据里的采购记录**（个性化），切忌群发复制模板。[同上]
- **印证/补充**：`signals.md`（渠道来源判断）+ `templates.md`（开发信个性化）。

### 1.18 领英开发客户（第三轮新增）
- **Headline 别写"销售"**——写"核心产品行业关键词 + 供应商/专家/产品经理"；客户看到"销售"第一反应是推销，多数不喜欢。[来源：zhuanlan.zhihu.com/p/509990546]
- 姓名=英文名+产品关键词；Summary=你是谁+能提供什么+优势+客户好处+认证+联系方式；配作品文件（参展/生产/客户合影照片）。[同上]
- 把控好友质量、互动点赞增加营销深度；好友申请消息要有吸引力和价值。[同上]
- **印证/补充**：`eq-communication.md`（换位思考）——领英资料打磨本质是"从客户需求出发自我介绍"。

### 1.19 样品寄送（第三轮新增）
- **"寄样品不是免费送礼，而是合作筛选"**——真客户能理解合理的样品费/运费/确认流程；需求不清一直要免费的是无效需求。[来源：xiaoman.cn/article/916]
- 样品费**透明化**：成本构成（材料/人工/包装/损耗 5-10%）+ 明细清单，避免"费用另议"的模糊表述。[同上]
- 报价单加粗标注："**样品费确认后直接抵扣首单，无额外附加费**"（减少疑虑）。[同上]
- "样品申请表"设为必填项，从源头减少无效需求。[同上]
- **印证**：`zh-playbook.md#S4` / `playbook.md#S4`（样品费照收、首单抵扣）——语料与技能做法完全一致。

### 1.20 汇率应对（第三轮新增）
- 中长期出口合同**协商人民币结算**（源头消除汇率风险）；框架长约设价格调整条款。[来源：safe.gov.cn 外汇局文章]
- 报价决策考虑汇率风险，可用掉期等工具锁汇。[来源：zoho.com.cn]
- **印证/补充**：`negotiation.md`（把汇率写进报价条件/条款，属于"客观标准+换条件"）。

### 1.21 交期延误处理（第三轮新增，含一条不采用）
- **报价时就加 7-10 天缓冲期**；一旦要延误，**第一时间告知**（不要等到货期当天），且邮件**第一句就开门见山**说延迟——老外思维是"委婉=绕弯子"。[来源：zhuanlan.zhihu.com/p/529993295]
- 原则：不逃避、不推脱责任、给方案给新交期、真诚但不滥说 sorry（过多 sorry 招人烦）。[同上]
- 让工厂定期发**生产进度表/照片**验证（"不要说你要看，说客户要看"）。[同上]
- ⚠️ **不采用**：语料里"合理的谎言该说就说，no cheating"——与技能红线（不编造、不假紧迫感）冲突。**正确的做法是选"专业且真实的解释"（工艺/配件/排产原因），而不是编理由**；编造一次被识破，长期信任归零。
- **印证**：`templates.md` 延误通知模板（开门见山+补救+新日期）。

### 1.22 大客户/项目型（第三轮新增）
- **客户采购五要素**（需求/价值/价格/体验/信任）+ **大客户销售六步骤**（客户分析→建立关系→挖掘需求→呈现价值→获取承诺→回收货款→二次销售）。[来源：jiandaoyun.com]
- 客户类型分"信息型/价格型/合作型/长期型"，**按类型调整沟通策略**。[来源：xiaoman.cn/article/931]
- 工具：SPIN（挖掘需求）+ FABE（呈现价值）+ "1+2+1" 成交模式。[同上]
- **印证**：`sales-methods.md`（SPIN/Miller Heiman 决策链）——"按客户类型调策略"正是 `framework.md` 客户分层的翻版。

## 2 本语料对技能的最大新增：催款/收款话术层

技能此前有"催单（下单）"模板，但**没有"催款（收款）"话术**。语料补齐（见 1.2）：

1. 尾款 → "款到即发"话术（正向通知+条件）
2. 资金紧张 → 分期方案（50%+两周清）话术
3. 老客户拖账 → 感情牌+责任推财务
4. 铁律：钱到才发货、定金不妥协、条款入合同

> 建议调用时机：`templates.md` 的"催单"与"PI 跟进"之后，若客户已确认 PI 但定金/尾款迟迟不到，翻本节。
