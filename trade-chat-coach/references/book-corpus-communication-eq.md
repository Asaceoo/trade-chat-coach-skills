## 2 三层框架：共情 → 高风险对话 → 难谈的话

### 2.1 非暴力沟通（卢森堡）— 把指责翻译成请求

**TOC 证据**：*译序 / 前言 / 语言是窗户（否则，它们是墙）/ 第一章 让爱融入生活 …*（公开目录 23 条）

**四步（可直接套）**：观察（不带评论的事实）→ 感受（我的感觉）→ 需要（我真正要什么）→ 请求（具体、可执行、不命令）。

**销售转译 📘**（这是最容易用错的地方）：
| 不要说（评论/指责） | 改成（观察 + 需求 + 请求） |
|---|---|
| 「您怎么一直不回我？」 | 「我上周三和昨天各发了一条（观察）。我这边怕耽误您的排期（需要）。您今天方便给我一句，是继续还是先放一放？（请求）」 |
| 「这个价格已经很低了。」 | 「这个价是按 [数量] 报的（观察）。再降我得动成本（需要）。如果能定到 [数量]，我再帮您申请一次。（请求）」 |
**边界**：四步是给你自己理清思路用的；发给客户时**要压缩成 1–2 句**，说成客户的话。

### 2.2 关键对话（格雷尼等）— 高风险场景不失控

**可执行点**：
- **从事实开始，不从结论开始**：说「这周发出 3 批中有 1 批延迟」而不是「你们不守时」。
- **保持安全感**：先声明共同目的（「我们都想这批别耽误您上线」），对方才敢说真话。
- **STATE**：陈述事实 → 讲出想法 → 征询对方观点 → 试探性表达 → 鼓励反驳。
**用在哪**：质量事故、严重延误、客户已发火、价格谈判破裂后的挽回。

### 2.3 高难度谈话（斯通等）— 把「吵什么」拆开

- 每场难谈都有三层：**发生了什么**（事实之争）、**情绪**（未被承认的感受）、**自我认同**（这件事对我意味着什么）。
- 可执行：客户骂的是 A（事实），气的是 B（没被尊重），怕的是 C（他被老板追责）。**先处理 B、再澄清 A、最后给他 C 的解法**。

## 3 表达与结构化：让客户 30 秒听懂

### 3.1 金字塔原理（明托）

- 四原则：**结论先行 / 以上统下 / 归类分组 / 逻辑递进**。
- 销售用法 📘：报价邮件第一句就写「能不能做、多少钱、多久到」；后面才是理由。客户没时间读推理过程。

### 3.2 结构化表达（黄漫宇，机械工业出版社 / 117,730 字）

- TOC 显示按「职场沟通难题 → 表达结构」展开；适合直接抄汇报与演讲骨架。
- 可执行：任何汇报先写一句话结论，再列 2–3 条依据，最后给一个请求（要他批什么）。

## 4 中文语境的情商聊天（内贸客户优先读）

- **高情商聊天术（张超）**：开口不求惊艳、只求不冒犯；赞美的落点在对方的**选择**而不是天赋（「您挑参数挑得很细」比「您真聪明」安全）。
- **蔡康永的说话之道**：核心是**给人留余地**——把「你错了」说成「我可能没理解对」。内贸饭局、微信语音场景最实用。
- **好好说话（马薇薇等）**：把沟通/说服/谈判/演讲/辩论分开给招式；**说服**那一块与本技能 `influence.md` 互补。
- **卡耐基**：原则仍有效（真诚关心、记住名字、让对方多说话），但**话术外壳过时**，不要照抄老派恭维句。

> 内贸提示：中文语境里「老板」「亲」「兄弟」是**礼貌**不是诚意（见 `SKILL.md` 与 `zh-playbook.md`）；读书给的是分寸，不是热情。

## 5 说服的结构（与 influence.md 互补）

**四步说服法（踢米尼）**：说服失败的五个根因——① 讲不清楚；② 对方听不明白；③ 对方听不进去；④ 对方不愿行动；⑤ **说服者自己的心理障碍**。

**用法 📘**：客户没反应时，先按这五条自查是哪一环断了，再决定用哪个模型（`objections.md`），而不是重复发送同一条消息。

**超级沟通者（都希格）**：不是所有对话都该用同一种方式——**实用型**（要结果）/ **情感型**（要共情）/ **社交型**（要连接）三者匹配错位，努力就白费。
用法：客户在情绪里时，先切情感型；等他冷静了再切实用型谈条款。

## 6 情绪与自我管理（业务员自己的那部分）

- **情绪价值型销售高手（陈思颖）**：把情绪价值做成可交付物——客户从你这儿得到的不只是货，还有「被认真对待」的体验。
- **销售就是要玩转情商（科林·斯坦利）**：本书 2200 人划线：「一些并不急于完成销售的销售员通常会比那些心急的销售员取得更大的成功」——**不追单**是有读者行为验证的。展开见 `book-corpus-sales-negotiation.md` §1 与 `courses.md` §4.6。
