# 信号词典：真买 · 比价 · 探路 · 风险

配套 `SKILL.md` 的 Step 2 使用。这里给的是**判据**，不是标签。

## 使用原则

1. **信号是概率，不是判决。** 任何单条信号都可能被反例推翻，所以同一判定至少要有 **2 条相互独立的证据**（不同时间、不同话题上出现的，才算独立；同一句话里反复出现只算一条）。
2. **两个方向都要找证据。** 人的本能是找支持第一印象的东西。判错方向的代价不对称：把真买当比价 → 丢单；把比价当真买 → 烧掉整月精力。所以查完"支持信号"，必须再查一遍"指向另一类的信号"。
3. **看行为，不看措辞。** 客户说什么最不值钱，客户**花了什么成本**最值钱：他的时间（视频会议、来回改图纸）、他的钱（付样品费、付定金）、他的内部资源（拉同事进来、给公司资料）。愿意付出成本的客户，才是真客户。
4. **沉默不是信号。** 已读不回可能是在度假、在等他的客户回复、或在走内部流程。要用下一次触达去测试，而不是靠猜。

## A 真买信号（Buyer）

| 信号 | 客户原话示例 | 为什么算真信号 |
|---|---|---|
| 主动给规格 / 图纸 / 型号 / 认证要求 | "Attached is our spec sheet, we need CE and RoHS." | 给具体参数是要花成本的，比价的人不会花 |
| 问交期、装箱量、HS code、具体目的港 | "What's the CBM for one 20ft? Can you ship to Jebel Ali?" | 这些是执行层问题，只有准备执行的人会问 |
| 透露下游客户 / 项目 / 门店 / 线上店 | "We supply 12 retail stores in Germany." | 交出商业背景 = 愿意让你了解他的生意 |
| 问完 MOQ 后转向谈小批量 | "Can we start with 200 pcs as a trial?" | 从"你的规则"转向"我们的路径"，是在找成交办法 |
| 追问付款条款细节 | "Is 30/70 T/T acceptable, or do you need L/C?" | 谈钱的方式 = 进入执行阶段 |
| 隔一段时间又回来问同一个产品 | "Back to the model we discussed in March…" | 说明他一直在推进，只是节奏慢 |
| 愿意付样品费 / 运费 | "Send me the invoice for the sample and freight." | 花钱 = 最强信号 |
| `let me check with my team` 之后带具体问题回来 | "My engineer asks if IP65 is available." | 内部真的在讨论，不是在敷衍 |
| 给数量区间，而不是只问 "best price" | "We'd need 1,500–2,000 pcs for the first year." | 有量的概念 = 有真实的采购计划 |
| 嫌贵但继续谈条款 | "Price is high, but what about the lead time?" | 拒绝价格却留在桌上，说明他要的是解决方案 |

## B 比价信号（Price collector）

| 信号 | 客户原话示例 | 怎么处理 |
|---|---|---|
| 一上来只要 price list / catalog | "Please send your full price list." | 不直接发全表；发 1–2 个匹配型号 + 反问 3 项信息 |
| 不给数量、规格、目的国 | （问了三次都答"just give me your price"） | 定性为比价，标准化回复一次 |
| 群发口吻 | "Kindly send your best price for all products." | 大概率同时在发给十几家 |
| 问完价格就消失，下次回来还是只问价 | 间隔长、每次只问价 | 归入 C 档，低频池 |
| 拒绝透露用途 / 目的国 / 公司信息 | "That's not important, just the price." | 信息不对称的单向索取 |
| 要 Excel 格式价目表 | "Send it in Excel so I can compare." | 直白地在做横向对比 |
| 拿"别人给我 XX"但不谈规格差异 | "Another supplier gives me $8." | 别降价，问规格基准（见 playbook S1） |
| 只关心单价，不问交期 / 质量 / 认证 | 全程只有价格字段 | 真买家一定关心"能不能按时给对的东西" |

> 注意：比价 ≠ 无价值。比价者中有一部分是"还没被说服的真买家"。区别在于——**你愿不愿意用一次低成本的回复去测试他**。测试话术见 playbook S2。

## C 探路信号（Explorer）

| 信号 | 客户原话示例 | 含义 |
|---|---|---|
| 问能力问题，而不是需求问题 | "Do you make this kind of product? Can you customize?" | 还在建立供应商地图 |
| 身份模糊：免费邮箱、无公司签名、无网站 | gmail/yahoo 且无落款 | 可能是个人、新公司，或同行小号 |
| 公开说自己在做市场调研 | "We are exploring suppliers for a new product line." | 项目可能还没立项，周期长 |
| 客气、热情，但从不落到数量和时间 | 聊了 20 条，仍然没有 qty 和 deadline | 关系型沟通，没有采购动作 |
| 问"你们出口到我们国家吗""有当地客户吗" | 关心你的经验而非产品 | 在评估你的可信度，还没进入选型 |

> 探路者要**长线养**：固定节奏、给行业信息、不投入定制化劳动。不要把探路者当真买家去追，那样两头都伤。

## D ⚠️ 风险信号（Scam / 套资料）

出现任意一条，就在输出里单独标红，并给出"验证动作"——不要直接下结论说对方是骗子（有误伤成本），但要让用户先验证再投入。

| 风险信号 | 验证动作 |
|---|---|
| 首单数量大得反常，且完全不砍价 | 视频会议验证公司实体；要求对方提供营业执照/网站/物流地址，交叉检索 |
| 催要邀请函 / 签证材料，对产品细节不关心 | 明确邀请函只在合同与定金确认后出具；查对方公司注册信息 |
| 要免费样品，还要你付运费，理由是"testing then big order" | 样品费照收、可在首单抵扣；运费到付。真买家接受这个规则 |
| 付款水单来自第三方、金额对不上、或截图模糊 | **以银行到账为准**，绝不凭水单发货；让财务直接与银行确认 |
| 指定"清关代理"或货代，要你先付一笔钱 | 拒绝任何由客户指定、且要你垫付的第三方费用 |
| 索要营业执照、法人身份证、银行账户、客户名单 | 只提供交易必需文件；客户名单绝不提供 |
| 新注册域名、邮箱名与公司名不符、网站是通用模板 | whois 查域名年龄；要公司官网邮箱回信 |
| 要求付款到私人账户 / 加密货币 / 西联 | 只走公司对公账户；这条没有例外 |
| 冒充大买家（知名品牌）用免费邮箱联系 | 通过该品牌官网渠道反向核实 |

## 反向证据清单（下判断前逐条自问）

- 判为**真买**时：他有没有付出过任何成本（时间/钱/内部资源）？他的时间线是否具体？他是否回避付款话题？
- 判为**比价**时：他给过目的国或数量吗？他问过交期或认证吗？他有没有拒绝过你的某个提议（拒绝也是投入）？
- 判为**探路**时：他问过价格吗？他的问题是否越来越具体？他有没有引荐同事？
- 判为**风险**时：有没有可能是文化差异（例如某些地区习惯先要全目录、先谈感情）？有没有可能是大公司采购流程导致的不合常理？

## 地区与渠道倾向（概率倾向，不作标签）

用作**加权**，不用作**判定**。同一个国家里，个体差异远大于平均差异。

- **西欧/北美**：重视认证、交期稳定性、可持续与合规文件；回复慢但一旦进入流程很规范。
- **中东**：先要 best price 是礼节性开场，谈判周期长；关系与当面/语音沟通权重高。
- **印度、巴基斯坦、孟加拉**：价格敏感、比价行为多、群发询盘比例高；但其中也有高质量进口商，要靠"给不给具体信息"区分。
- **独联体/俄罗斯**：常用 Telegram/WhatsApp，回复节奏慢、冬季与假期影响明显；技术参数要求往往很硬。
- **拉美**：重关系与账期，付款和清关周期不确定性高，报价时把时间与汇率风险算进去。
- **东南亚**：华人商圈重信任与介绍；MOQ 灵活度是重要竞争力。
- **渠道**：B2B 平台询盘群发率高、身份核实成本高；展会/老客户转介绍的真实度最高；WhatsApp/Telegram 私聊最容易判断真伪，因为要拿到号码本身就有成本。

## 置信度标定

| 置信度 | 条件 |
|---|---|
| 高 | ≥3 条独立信号指向同一判定，且查不出实质性反向证据 |
| 中 | 2 条独立信号，或存在 1 条明确的反向证据 |
| 低 | 只有语感/口吻/单条信号，或截图残缺导致关键信息缺失 |

**低置信度不是不给结论**，而是要写清"补哪一条信息就能把它变成中或高"——这才是对用户真正有用的部分。

## 常见误判

1. **把礼貌当意向**："Thanks, will come back to you." 在多数语境里是婉拒。
2. **把询价量当采购量**：平台询盘里的 10,000 pcs 常常是复制粘贴。
3. **把压价当没预算**：压价往往是采购流程的规定动作；真没预算的人不会追问交期。
4. **把慢当不感兴趣**：很多真实买家一个月才动一次，因为他在等自己的客户确认。
5. **把热情当信任**：热情可能只是他的沟通风格，信任体现在他愿不愿意为你承担风险。
6. **把"不回复"当结束**：多数订单死在第三次跟进之前。
