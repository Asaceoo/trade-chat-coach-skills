# 中文场景剧本库（内贸 / 华语客户）

配套 `SKILL.md` 使用。**判断逻辑与外贸完全一致**——四必答题、承诺阶梯、信任度刻度都通用；不同的只是**表面信号、渠道、付款方式和风险点**。

用在：客户说中文（内贸、港澳台、东南亚华商、海外华人采购），或中文平台（1688 / 微信 / 抖音私信 / 电话）上的沟通。

## 0 中文语境的四条底层差异

1. **称呼的礼貌程度和购买意向几乎不相关。** "老板""亲""兄弟""您"是默认社交润滑剂，不是诚意证据。这一点比英文语境更明显——英文里 `Dear` 已经算正式，中文里叫"老板"可能只是习惯。**判断依据只有一条：他愿不愿意给出具体信息、愿不愿意付出成本。**
2. **渠道更私密，身份线索更少，但验证手段更多。** 微信/QQ 号没有公司域名邮箱可查，但你可以**直接打电话、直接视频、直接看朋友圈**——中文语境下"敢不敢接视频/电话"是极强的验证动作，成本比要营业执照低得多。
3. **价格话术高度模板化。** "给个底价""能不能便宜点""走量""我是做工程的""以后长期合作"——这些和英文的 `best price` 完全等价：**是流程动作，不是购买信号**。真正的信号是他给不给规格、数量、时间、用途。
4. **付款与票据是内贸的生死线。** 定金比例、账期、承兑汇票、开票类型（增值税专票/普票）、对公还是对私——中文语境里一笔单子的风险几乎全在这里，比外贸更集中。

## 1 中文信号词典

### 真买信号

| 信号 | 客户原话示例 | 为什么算真信号 |
|---|---|---|
| 给具体规格 / 图纸 / 型号 / 参数 | "型号发你了，要 304 不锈钢，壁厚 1.5" | 给参数要花成本 |
| 问交期 / 装箱 / 物流 / 安装 | "多久能到？能赶上 10 月开业吗？" | 执行层问题，只有准备执行的人问 |
| 说得出用途和场景 | "我们做的是连锁餐饮门店，要 30 家店的量" | 交出商业背景 |
| 主动说下游或项目 | "这个项目甲方是 XX，我们中标了" | 有真实项目 |
| 问付款、开票、合同 | "能开专票吗？走对公还是怎么结？" | 进流程 |
| 愿意付定金 / 打样费 | "打样费多少，我转你" | 花钱 = 最强信号 |
| 愿意接电话 / 视频 / 来厂 | "你把地址发我，我周末过去看看" | 付出时间 |
| 引荐同事或领导 | "我把我们采购/技术拉进群" | 内部真在推 |
| 给数量区间而非只问价 | "首批 500，全年大概 3000" | 有采购计划 |
| 嫌贵但继续谈条件 | "价格高，但账期能谈吗" | 拒绝价格却留在桌上 |

### 比价信号（中文高频版）

| 信号 | 客户原话示例 | 怎么处理 |
|---|---|---|
| 只发"在吗""多少钱" | "在吗" / "什么价" | 不回"在"，一次性把信息要素发过去 |
| 只要报价单 / 价目表 | "把你们报价单发我一份" | 发 2 个匹配型号 + 反问 3 项 |
| 反复说"给个底价"但不说规格 | "你就说个实在价，别虚的" | 底价 = 比价表最有价值的一格，不给 |
| 拿"别人比你便宜"但说不出配置 | "别家比你这便宜一半" | 问对比基准（型号/材质/工艺/含不含税含不含运） |
| 群发感 | "XX 产品报价发一下，我这边要用"（无任何细节） | 标准化回复一次 |
| 问完价消失，下次回来还只问价 | — | 归 P3 档 |
| 拒绝说用途 / 地点 / 公司 | "你先报价就行" | 单向索取信息 |
| 只关心单价，不问交期/质量/售后 | — | 真买家一定关心"能不能按时给对的东西" |

> **"我是做工程的""我们走量""长期合作"这三句话，单独出现时价值为零。** 判断方法是紧接着问一句具体的：什么工程、什么量、什么时候要。答得上来就是真的，答不上来就是话术。

### 探路信号

| 信号 | 客户原话示例 |
|---|---|
| 只问能力，不问需求 | "你们能做这个吗？能定制吗？" |
| 身份模糊 | 微信无朋友圈、无公司、头像网图、新号 |
| 说自己"先了解一下" | "我先看看，有需要联系你" |
| 客气但从不落到数量和日期 | 聊很久，始终没有"多少、什么时候" |
| 问"你们还给谁供过货" | 在评估你的可信度，还没进入选型 |

### 内贸特有风险信号

见第 5 节完整清单，这里列最高频的六条：
垫资 / 假招标收保证金 / 要方案但不付打样费 / 先货后款且是首单 / 商业承兑汇票 / 要求回扣到私人账户。

## 2 中文场景剧本 S1–S12

话术可直接复制。`[ ]` 处填真实数字，**不填就别发**。

### S1 "太贵了，给个实在价"
**识别**：一句否定，没有对比基准、没有目标价、不谈配置差异。
**目标**：阶梯 1 → 2，拿到对比基准或目标价。

> 明白，价格我肯定给你实在的。不过为了不让你白比——他那边报的是哪个型号、什么材质、含不含税和运费？配置不一样的话，价差可能在材料和工艺上，我不想让你拿两个不一样的东西比。

对方给了目标价时：

> 你把目标价和数量告诉我，能做到我直接说能做到；做不到我也直接说，然后告诉你差在哪（材料、工艺、包装还是账期），不玩"先报高再让"那套。

**别做**：立刻降价；说"我们质量好"；写三段成本说明（他不看）。

### S2 只问"多少钱""发个报价单"
**识别**：连续两三次只要价格，规格/数量/用途一个都不给。
**目标**：用三项信息换一个价，**不发全表**。

> 报价单我这边有 60 多个型号，价格随数量和配置走，整份发给你反而看不准。你告诉我三件事——用在哪、要多少、什么配置——我直接给你 2 个最合适的型号和实价。

**别做**：把整张价格表发出去。

### S3 已读不回 / 不回微信
**识别**：前两次跟进无回应。先分清"没看到"还是"不想回"——**换个渠道打一通电话**就能区分。
**目标**：用**新信息**换一次回复。

> 王总，补一条可能有用的：上次说的那款改成新模具了，500 件以上的单价降了大约 [X]%，账期也能从 [A] 调到 [B]。如果这阵子不急，你说个时间我到时候再找你。

收尾信（把决定权还给他）：

> 我不多打扰了，这个先放我这儿。项目要是重新启动，你回我一句就行，我当天给你更新价格和排期。

**别做**：连发"在吗""考虑得怎么样"；表达委屈；把"不回"直接当拒绝。

### S4 要免费样品
**识别**：要免费样品 + 你付运费，理由是"测试完就下大单"。
**目标**：把样品变成一次低成本的承诺测试。

> 样品没问题。两个方式你选：一是运费到付，我今天就寄，logo 也能帮你先打上，你直接看印刷效果；二是样品费和运费我先开单收，首单全额抵掉。你看哪个方便？

**别做**：无条件免费 + 包邮；因为一条请求就断定对方是骗子。

### S5 要独家 / 区域代理
**识别**：还没有首单，就要某市/某省的独家。
**目标**：把"给不给"变成"用什么条件换"。

> 独家可以谈，我更愿意做起来之后再给你写进去，而不是同时答应三家。我们一般看三个数：首年提货量 [X]、季度进度、以及你这边能覆盖的渠道。你把这两个区域的年度预估发我，我按量给你配政策。

**别做**：一口答应；生硬拒绝；给无条件的口头承诺。

### S6 要账期 / 承兑汇票
**识别**：首单就要账期，或提出用银行/商业承兑结算。
**目标**：给**阶梯**，不是"给"或"不给"。

> 首单我们走 [30]% 定金、发货前结清，这样价格才能给到现在这个数。合作两三次之后可以谈月结，也能谈承兑——**银行承兑可以，商业承兑要看开票主体**。首单先按定金走，你看行不行？

**别做**：首单全赊；不查开票主体就收商票（商票的兑付风险在你手上）。

### S7 迟迟不签
**识别**：都谈好了，就是不给决定。
**目标**：用**真实**的时间锚换一个决定。

> 有两件事我提前跟你说一声：这个月的排产位到 [日期] 就排满了；另外包材那边 [日期] 起调价——这条是他们通知的，不是我在催。你能在 [日期] 前定数量，这两个我都能给你留住。要是需要再想想，也跟我说一声，我按你的节奏排。

**别做**：编造假涨价、假库存、"最后一个名额"。

### S8 "你们是厂家还是贸易商？"
**识别**：客户在筛供应商类型。
**目标**：诚实 + 转价值。

> 我们是贸易公司，[产品] 有自己的组装线——关键工序的品控我盯得住，出口单证、认证、物流这些也由我这边一个人对你。如果你这边硬性要求只跟工厂合作，你直说，我也不会绕你。

**别做**：谎称是工厂（一次验厂就崩）。

### S9 砍起订量
**识别**：想先小批量试单，低于你的起订量。
**目标**：用"首单特例"换承诺，并说明只是首单。

> 起订量是 [X]，因为材料是按批量订的。首单我可以给你做到 [Y]，两个条件：跟别的单拼一起生产，单价按小批量算。试单没问题的话，第二单开始按正常起订量走。

**别做**：无条件破起订量；为凑小单偷换材料。

### S10 客户在多家人之间比
**识别**：明显同时在谈几家。
**目标**：成为**最容易合作的那一个**，不是最便宜的那一个。

> 你多问几家是对的。你可以拿三件事比我们：技术问题当天回、单证一次过不用你催第二遍、发货前主动给你拍生产照片。下一个问题你就拿这三条试我。

**别做**：诋毁同行；只靠降价。

### S11 同行套价 / 套方案
**识别**：问得比终端还细，不谈量不谈用途。
**目标**：保护价格体系和方案。

> 可以合作。我们价格是分渠道的，所以我得先确认一件事：你是自己项目用，还是转手做？如果是转手，你告诉我做哪个市场，我按合适的利润结构给你报，而不是给你一个零售价。

要方案/图纸时：

> 方案我可以出，出之前先确认两点：一是用途和现场条件，二是打样/设计费 [X]，下单后全额抵。这不是信不过你，是我们的方案都是按你的现场做的，不做通用版。

**别做**：直接给底价；把所有人都当同行防（会得罪真实中间商，而中间商常是大单来源）。

### S12 老客户压价 / 消失后回来
**识别**：老客户返单要降价；或沉默一段时间后恢复联系。
**目标**：不追问沉默，直接给新价值。

> 好久不见。这段时间我们上了 [新配置/新认证]，交期从 [X] 天缩到 [Y] 天。要不要我按现在的价格和船期把上次那单更新一版给你？

老客户返单议价：

> 按 [数量] 返单，我按去年的价给你保。低于这个量，原材料从 [日期] 起涨了 [X]%——我把涨在哪一项拆给你看，比偷偷在料上省要好。

**别做**："你怎么这么久没回我"；对老客户一次性大幅让价（会永久重设他的价格预期）。

## 3 中文特有场景 S13–S16

### S13 客户只发"在吗"
**识别**：只发"在吗""在不在"，不说事。可能是在群发试探谁在线。
**目标**：不回"在"，直接把球踢回去，让他一次说清。

> 在的。你直接说要问的事就行，我这边一次性给你答案——要报价的话，把用途、数量、配置发我，我马上算。

**别做**：回一个"在"然后干等（这等于把节奏交给一个可能在群发的人）。

### S14 "先出个方案/图纸我看看"
**识别**：要你投入劳动（设计、打样、算方案）但不付任何成本。
**目标**：用条件换方案，同时不把真客户推走。

> 方案可以做。两个方式：一是你先给我现场尺寸和使用条件，我出一版**框架方案**（不含细节图纸），你看方向对不对；二是要出到可施工的详细图纸，我们收 [X] 设计费，下单全额抵。你选哪个？

**别做**：免费出完整方案给一个没给过任何具体信息的人——这类"套方案"在内贸里非常常见。

### S15 招标 / 要保证金 / 要标书费
**识别**：对方以"项目招标"名义要你先交钱或先垫资。
**目标**：验证 + 守住钱。

> 招标我们可以参与。麻烦把三样发我：招标公告或邀请函原件、招标主体全称和统一社会信用代码、以及保证金条款。**保证金只能从我们公司基本账户转到招标人的法人账户**，收款方是个人账户的一律不参与。

**别做**：往个人账户交任何"保证金/标书费/关系费"；在没有合同的情况下垫资生产。

> 参考（以现行规定为准）：政府/国企招标的投标保证金须按招标文件规定从投标人账户转入招标人指定账户，收款方为个人账户本身就不合规；投标保证金金额也有上限规定（《招标投标法实施条例》为不超过招标项目估算价的 2%）。超出常规比例的"保证金"通常不是保证金。

### S16 要回扣 / 要求打到私人账户
**识别**：对方（通常是采购个人）要求返点到私人账户。
**目标**：守住合规底线，同时不撕破脸。

> 价格上我能给的优惠都在明面上，走对公、开票、进合同。私人账户这块我这边做不了，公司财务过不去。你要是想让这单在价格上更合适，我们可以在数量、账期或者配置上想办法，这些我都能帮你争取。

**别做**：为了成单配合走私人账户。这不只是"风险"——给对方采购个人回扣，可能构成**对非国家工作人员行贿**；对政府/国企人员则可能构成**行贿**，对方相应可能构成受贿。双方都要担责，且**行贿方一样被追诉**。

**还有一个容易被忽略的动作**：在微信上**留痕明确拒绝**（就是上面那段话），是对你自己的保护。将来这单出任何问题——质量纠纷、对方公司审计、对方被调查——你的聊天记录是唯一能证明"我没给"的东西。反过来，含糊其辞、不回、或者口头答应，都可能被解读成默许。

## 4 中文禁句 / 油腻话术替换表

| 别写 | 换成 |
|---|---|
| 只发"在吗"然后等 | 一次性把事说完："在的，关于 [产品]，我需要 A/B/C 三项，你方便给我吗" |
| 过度"亲""老板""兄弟" | 用姓氏 + 职务："王总""李经理" |
| "我们是源头厂家，质量最好" | 给可验证的："这条线是我们自己的，我发段车间视频给你" |
| "全网最低价""亏本清仓""最后一天" | 不编造。用真实的排产期、材料价、舱位 |
| 连发多条 60 秒语音 | 文字写要点，语音只作补充 |
| "您看什么时候方便？"（空转） | 给两个具体选项："周三下午或者周四上午，你挑一个" |
| "麻烦尽快回复" | 给理由和截止点："这周五前定的话，能排进本月产能" |
| "考虑得怎么样了？" | 带新信息："补一条：那款的最小起订量我帮你争取到 [X] 了" |

## 5 内贸特有风险清单

出现任意一条，标红并给验证动作。**不要直接下"骗子"结论，但先验证再投入。**

| 风险信号 | 验证动作 |
|---|---|
| 首单要你垫资生产 | 拒绝垫资；只接受定金排产，或要求对方提供担保/预付款 |
| 首单就要"先货后款" | 查主体工商信息、实缴资本、经营年限；要对方提供对公账户与合同主体一致的证明 |
| 商业承兑汇票（非银行承兑） | 只收银行承兑；商票必须核开票主体资信，必要时贴现成本提前算进报价 |
| 以招标名义收保证金/标书费，且打个人账户 | 一律不参与；只走对公且账户名必须与招标主体一致 |
| 免费要样品还要你付运费 | 运费到付，样品费首单抵扣 |
| 要完整方案/图纸但不付打样费、不给现场信息 | 只出框架方案；详细图纸收设计费、下单抵扣 |
| 索要营业执照、法人身份证、开户许可证 | 只提供交易必需文件；身份证类一律不给 |
| 回扣到私人账户 | 拒绝；优惠走明面（价格、账期、配置） |
| 冒充大企业/国企/政府项目 | 通过该单位官方渠道反向核实；要求招标编号与主体全称 |
| 要求"陪标""围标" | 直接拒绝。这类要求本身违法，参与即担责 |
| 微信新号、无朋友圈、头像网图、拒绝电话视频 | 主动打一次电话或发视频邀请；**拒绝接电话的"大单"不是单** |
