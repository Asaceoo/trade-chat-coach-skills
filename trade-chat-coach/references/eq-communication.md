# 高情商沟通：让客户愿意回你、愿意跟你说真话

配套 `SKILL.md` 使用。**高情商不是"会哄人"，是"让客户在你面前感到安全，于是愿意跟你说真话"**——真话才是成交需要的信号。

## 0 怎么用

- 客户情绪化/指责你/不回复 → 读第 3、4 节句式库。
- 想理解"为什么这句有用" → 读第 1 节框架。
- 想验证"情商到底值不值钱" → 读第 5 节实证（答案可能反直觉）。

## 1 核心框架速览

| 框架 | 内核一句话 | 迁移到销售 |
|---|---|---|
| 非暴力沟通（Rosenberg） | 观察（不评判）→ 感受 → 需要 → 请求 | 跟客户说"您三次问的都是价格，没说用途——我这边算不准"，而不是"您怎么老只问价" |
| 关键对话（Patterson 等） | 安全感 = 共同目的 + 相互尊重；沉默和暴力都是失能 | 客户发火时先重建安全感，再谈事 |
| 高难度谈话（哈佛 PON） | 三层对话：事实层、感受层、身份层；讲"第三故事" | 被指责"你们延误了"时，先承认他看到的版本，再补充自己的版本 |
| Fierce Conversations（Susan Scott） | 把最重要的话说到台面上；情感尾迹比内容更持久 | 价格/交期/坏消息，直说比绕弯子留下的关系更好 |
| 蔡康永《说话之道》 | 把别人放在心上；少说"我"，多说"你" | 跟进消息先给客户要的，再带你想说的 |
| 《好好说话》 | 沟通/说服/谈判/演讲/辩论五维，权力关系决定打法 | 对上位者（老板/大采购）用说服而非辩论，对平级用商量 |
| 《所谓会说话就是换位思考》 | 每句话都从对方视角出发 | 报价格时先说他能得到的，再谈价格 |

## 2 高情商句式库（≥30 条：场景 / 别这么说 / 这样说）

**NVC 系（观察-感受-需要-请求）**
1. 客户只问价不给信息｜别：`您这样我没法报价`｜这样说：`您三次都在问价格，没提规格和数量——我按猜的报，对您没用。给我三个数：数量、规格、目的港，我 2 小时内给您实价。`
2. 客户消失后回来｜别：`您怎么这么久没回我`｜这样说：`上次聊完快一个月了，正好有新信息补给您：这款单价降了 [X]%。`
3. 客户指责你｜别：`不是我们的问题`｜这样说：`我能理解您为什么着急。先不争这个，我们把卡住的事解决掉。`
4. 要拒绝客户的不合理要求｜别：`不行`｜这样说：`这个我确实做不到，但我能做到的是 [替代方案]，您看行不行？`

**关键对话系（安全感 / 共同目的）**
5. 客户要降价而你不想降｜别：`我们价格很实在了`｜这样说：`我们都想把这单做成，这点一样。价格我动不了那么多，但我能在 [账期/交期/服务] 上帮您，这样您这单的实际成本差不多。`
6. 客户发火｜别：`您别生气`｜这样说：`您说的这个确实让人上火。我们把问题拆开，先解决最疼的那个。`
7. 客户说"再考虑"｜别：`考虑什么呀`｜这样说：`是价格、时间还是信任的问题？您直说，我好知道往哪儿使劲。`
8. 表达不同意见｜别：`您这想法不对`｜这样说：`如果只看价格确实像这样。换个角度看 [成本/交期/总成本]，结论可能不同。`

**高难度谈话系（第三故事 / 承认感受）**
9. 客户抱怨交付慢｜别：`我们一直准时`｜这样说：`您等的这 [X] 天确实难熬。上次延误是我这边流程问题，我已经改了，这次给您书面交期。`
10. 客户说"你们跟别家没区别"｜别：`我们很有优势`｜这样说：`如果只比参数，确实差不多。但您上次说的 [具体痛点]，我们处理方式和别人不一样。`

**Fierce 系（把话说到台面上）**
11. 客户要你含糊承诺｜别：`应该没问题`｜这样说：`交期我说准数：收到定金后 [X] 天，超一天我提前三天告诉您。`
12. 客户砍价到底｜别：`最低价了`｜这样说：`这个数是底了，我再让就是在成本里偷工，那对您更亏。`

**蔡康永系（把客户放在心上）**
13. 跟进开场｜别：`在吗？`｜这样说：`王总，上次说的 [产品] 我补了两个新信息，您 2 分钟就能看完。`
14. 客户说"我很忙"｜别：`就耽误您一分钟`｜这样说：`您忙我不多占时间，答案我已经整理好，您有空扫一眼，有疑问随时找我。`

**好好说话系（权力关系）**
15. 对上位者/大采购｜别：`您应该选我们`｜这样说：`您做决定我配合，我把风险和收益各列一页，您看哪条对您最重要。`
16. 对平级/同行｜别：`你听我的`｜这样说：`我这么做过 [X] 次，踩过的坑可以给你省下来，你参考。`

**倾听系（复述确认 / 情绪标注 / 留白）**
17. 确认理解｜`我理解一下：您要的是 [复述]，对吗？`
18. 标注情绪｜`听起来您对 [账期/交期] 有顾虑。`
19. 留白｜说完后停 3 秒，不急着接话——客户会补出真话。
20. 追问一句｜`除了这个，还有别的卡点吗？`（他说的第一个往往不是最关键的）

## 3 难缠场景四步流程

### 被指责（"你们延误了/质量不行"）
1. 承认感受（不辩解）：`这确实耽误您了。`
2. 复述事实：`我先确认下情况——是 [日期] 那批对吧？`
3. 给解法：`我今天内给您 [具体动作：重发/补偿/加快]。`
4. 收口：`您看这个处理方式行不行？`
> 禁忌：第一步辩解 = 后面全白说。

### 被压价
1. 不接价，接利益：`价格我们先放着，您这单的预算量级是？`
2. 拆配置：`我们比一下规格，别拿两个不一样的东西比。`
3. 换条件：`单价让不了，但 [运费/账期/包装] 我能帮您省。`
4. 底线收尾：`这个数做不了，不耽误您时间；量上来了随时找我。`

### 被冷落（已读不回）
1. 不追问"为什么不回"。
2. 换渠道试一次（电话/语音）。
3. 带新信息再发（不是催）。
4. 收尾信，把决定权交还：`我先收起来，您启动时回一句。`

### 对方发火
1. 降低音量与速度（文字则缩短句子）。
2. 标注情绪：`您现在很火，我理解。`
3. 共同目的：`我们都想把这单做成/把问题解决。`
4. 拆最小问题：`先解决 [最小一件事]，剩下的我负责跟进。`

### 要拒绝
1. 直接说不做什么（不含糊）。
2. 立刻给替代。
3. 说明理由（一句，不辩护）。
4. 保持尊严对等，不道歉过度。

**拒绝的 4 个心理学方法**（2026-10-08 补充）：从关系维护的一般沟通实践看，面对请托时直接硬拒容易引发对抗、损伤关系，因此需要**让"不"保持清晰，同时在态度上做软化代偿**，而不是靠愧疚或拖延来回避。**通用前提：一切方法都要以一句不含糊的"不"为前提——可以软化、不可消音。**
- **时间换空间**：当下不想答应又怕尴尬，先说"`这个我记一下，[今天/明天 X 点]给你准话`"，给自己留决策缓冲，避免仓促承诺——**但必须带明确时限、且到点一定要回**，绝不可用"晚点回"拖成变相失联。
- **把"请托→答应或拒绝"改成"先商量→再做决定"**：不直接判生死，先把条件/可行性摊开谈，并保证最终仍给出明确结论，对方会觉得你在帮忙而非推诿——"`这样我们看看有没有别的办法`"。
- **先说不、再幽默化解**：**先给一句不含糊的"这个我做不了"**，再补轻松一两句卸掉敌意（"`我帮你问问XX？`"）。幽默只做软化、**不替代拒绝本身**；正式/严肃场合慎用，避免对方听不出边界。<br>可参考"`这件事我实在不能答应，不过别担心，我可以帮你想想别的路子。`"
- **温和坚定 + 给参与感**：拒绝时说清边界但邀请对方共建可行方案（"`这件事我配合不了，但这几件我可以`"），比冷拒更易被接受（参见 influence.md 温和坚定）。

### 要催单
1. 带新信息（不空催）。
2. 给真实时间锚。
3. 给选择权：`您这周定我排产，或者我先留位到 [日期]。`
4. 收尾不纠缠。

## 4 倾听技术（聊天场景版）

- **一次只问一个问题**（信息缺口按优先级排，见 SKILL.md 必问清单）。
- **复述确认**：`我理解一下，您要的是…`——确认理解比继续推销值钱。
- **情绪标注**：把客户的情绪说出名字，他就愿意继续说（**注意：标注用母语才有效，见第 5 节**）。
- **留白**：说完问题后沉默，让客户填。业务员最常犯的错是替客户回答自己的问题。

## 5 实证发现（为什么"情商高"要转译成动作）

| # | 发现 | 出处 | 对用户实操的含义 |
|---|---|---|---|
| 1 | **"对客户好"不如"为这个客户改说法"**：适应性销售行为同时提升自评、经理评与客观绩效；而客户导向只与自评绩效相关 | Franke & Park, 2006, *JMR*（元分析，155 个样本、31,000+ 销售人员） | 微笑礼貌是标配；真正带来业绩的是**针对每个客户调整话术** |
| 2 | **情绪智力对销售绩效没有直接效应**，完全通过"适应性销售行为"中介 | 2017 年马来西亚金融业销售研究（SEM）；Joseph & Newman, 2010 元分析（EI↔绩效校正 r≈0.24–0.30） | "情商高"必须变成"他会根据客户改说法/改节奏"才有用 |
| 3 | **情绪标注只在母语中有效**：把情绪说出名字能下调杏仁核反应，但仅限优势母语；非优势语言无效 | 2026 年 *PNAS* 双语研究（N=151） | 外贸里安抚客户情绪，**用中文做不了**——要用客户的母语去标注情绪，或用行动而非语言安抚 |
| 4 | 峰终定律：体验评价由峰值与结尾决定 | Kahneman（见 influence.md） | 每次沟通的收尾句决定客户对你这轮的整体评价 |

## 6 常见误区（哪些"高情商话术"其实很油腻）

1. **过度道歉**："实在对不起/抱歉打扰您"——把姿态放低不等于高情商，尊严对等才是。
2. **油腻恭维**："老板英明""您太有眼光了"——消耗信任（zh-playbook 禁句表）。
3. **情绪词轰炸**：满屏"~""亲""呀"——中文 B2B 语境里像诈骗话术。
4. **替客户回答**：问完问题自己接"是不是这样？"——留白比抢答值钱。
5. **回避坏消息**：交期要超了不说，拖到最后一刻——高情商是把坏消息说到台面上（Fierce）。
6. **把"共情"演出来**：标注情绪但不真诚，客户一次就识破。
