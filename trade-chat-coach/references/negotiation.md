# 谈判学：价格谈判、让步与议价

配套 `SKILL.md` 的 Step 5 使用。**价格谈判的正确姿势不是"会砍价"，而是"上桌前想清楚三件事"：我的底线（BATNA）、对方的利益（不是立场）、以及每次让步换回什么。**

## 0 怎么用这份文件

- 客户开始谈价（"太贵了""别人比你便宜""给个最低价"）→ 读第 2、3 节。
- 你要主动报价/还价 → 读第 3 节（锚定）和第 4 节（让步阶梯）。

- 谈判陷入僵局/情绪化 → 读第 6 节（原则谈判与战术共情）。

## 2 原则谈判四要素（Fisher & Ury，任何价格谈判的地基）

1. **把人与问题分开**：对事不对人。客户说"你这价不合理"→ 回"价格我们先放一边，先看你要什么配置、什么时候要"——把他拉回利益层面。
2. **关注利益，而非立场**："太贵"是立场；背后的利益可能是"预算只有 X""要和别家比价交差""急着要货"。**问出利益，价格就好谈**。
3. **创造双方都赢的选项**：不谈单一价格，谈"组合"（数量、账期、交期、服务）。
4. **用客观标准**："这个价不是我拍的，是材料成本 + 标准毛利算出来的"——比"最低价给你了"可信。

## 3 锚定与反锚定

**锚定效应（Tversky & Kahneman 1974，A 级）**：先出现的数字会影响后面对价格的判断。第一次报价=锚。**谁先报价谁锚定**（你有成本底牌时，主动报价；你完全不知道市场价时，让对方先出）。

**报价动作**：
- 给区间不给单点：`1200 件约 USD [X–Y]/pc`（区间锚定 + 留谈判空间）。
- 报价前先建立参照物："这价格对标的是 XX 配置/含认证/含运"——让锚变得有道理。
- 锚定到"他更在意的代价"上：`这价格比你现在返工/停线的成本低`（SPIN 的 I 问题 + 锚定叠加）。

**反锚定（对方先报了低价）**：
- 忽略法：不接他的数字，直接问需求："这个价我们按什么配置谈？"
- 重锚法：给出你的配置对应的价格区间，让他重新评估。
- 拆分法：把价差拆到配置/服务/账期上，逐项比对（同规格才可比）。

### 3.5 《哈佛经典谈判术》清单（Malhotra & Bazerman；微信读书推荐值 908 / 2,433 人评，见 `sources.md` §1；豆瓣评分表未收录该书）

这是哈佛商学院教授版本的"上桌前准备"，比通用建议更硬核：

**准备谈判 5 步法**（报价前 5 分钟过一遍）：
1. 评估自己的最佳替代方案（BATNA）
2. 计算自己的底线
3. 评估对方的最佳替代方案
4. 计算对方的底线
5. 评估协议区间（ZOPA）

**减少锚定影响的 5 个策略**（对方先抛了数字时）：
1. 忽略对方的锚
2. 区分"信息"和"忽悠"
3. 不要陷入对方的锚
4. 还一个锚定价，然后双方再调整
5. **给对方时间和台阶，让他在不失面子的情况下调整报价**（保住关系，比赢一个数重要）

**正确报价的 4 个要素**：
1. 把整个议价区间纳入你的价格
2. 为报价提供理由（有理由的锚更硬）
3. 期望要高，但现实
4. 把谈判背景和双方关系考虑进去

**讨价还价 7 策略**：
1. 聚焦对方的底线和最佳替代方案，而不是他的报价
2. 不做单方面让步
3. 不怕沉默
4. 给让步贴标签（让对方知道你让了什么）
5. 明确定义对等（我让价，你加量/缩短账期）
6. 使用条件让步
7. 理解让步幅度递减对对方的影响（越让越少 = 到底了）

**多议题创造价值**：对方在价格上纠结时，引入发货时间、资金、质量、合同时限、服务支持、担保、合作前景等议题——**单议题谈判是零和，多议题谈判才能双赢**。这就是"谈组合不谈单价"的理论出处。

**谈判心理偏误（让对方和你自己都别犯）**：零和偏误（以为别人赢我就输）、炫目偏误（被表象晃花眼）、非理性投入升级（已投入越多越不肯撤）、自我中心主义、自利归因、后悔厌恶。**识别对方偏误 = 找到突破口；识别自己偏误 = 避免白送。**

### 3.7 《绝对成交》三段谈判策略（Roger Dawson，设局-中场-收局）

> Dawson 体系把谈判拆成**开局 → 中场 → 终局**三段，每段有固定套路。注意：这是**谈判姿态技巧**，讲究"怎么给出/收到价格"，**不是虚假报价**——所有动作都不能违背真实成本与承诺，否则就是红线（见 zh-playbook 禁句）。

**开局（锚定与姿态）**
- **敢于开价 / 不先让价**：先亮你的合理锚（有成本理由），别一上来就示弱。
- **框定范围**：给区间不给单点（如 `这批 USD [X–Y]/pc，看数量和交期`）——区间锚定，留谈判空间。
- **绝不接受第一次报价**：对方第一口就答应，等于告诉他"报低了"。哪怕要接受，也说"这个价我再跟老板确认，别急着定"。
- **学会表现惊讶**（对方开价离谱时）：不是演戏，而是表达"这个数出乎我预期"→ 逼对方重新说一个。可配合沉默。**使用前提（盲测整改）：仅用于明显离谱的报价；语气须真实；正常报价也装惊讶=砍价表演，损耗信任**。校准话术：`这个数比我预期高不少，您看怎么调整咱们才能往下谈？`
- **扮演不情愿的卖家**：简单说"这个价其实我这边不顺"，配合条件让步，而不是冷脸拒绝。**姿态级，不虚构。**
- **钳子策略**：对方谈到一半压价，你回一句 `这个价我们再探讨下有没有别的解法`，不接死价，把球打回去。本质 = "别只盯这一个数字"。

**中场（僵局与推进）**
- **更高权威法**：`这个价我个人觉得可以，但要走一下我们审批流程`——给自己留缓冲，避免当场顶死。**不是撒谎推责，是"决策需要流程"的如实表达。**
- **避免对抗性谈判**：僵住时翻到 SPIN 的 I 问题，回到利益："我们卡在价格上，是因为预算，还是要和别家交差？"
- **锁预期，不锁价**（B站"谈判技巧"评论，经验型）：客户在价格上反复拉扯、报价预期锁不住时，**不要继续在单价上跟对方博弈**——转为锁定**成交预期与决策时间**（"价格预期锁定不住，就锁定成交预期，改变他的决策体系"）。一上来就陷入讨价还价的谈判，本质是把自己拖进了"只比价"的窄局。
- **持续衰减的服务价值**：提醒"今天谈的附加服务/赠品，拖久了不一定还有"——用**真实的时间锚**促单，不虚构倒计时。
- **永远不要主动提议分摊差额**：不让价反而问"那我们来谈总价里其他的部分怎么优化"，把焦点从单价挪开。
- **烫手山芋**：把对方的难题如实还给对方，让他也承担："账期三个月这个，您这边做得了主吗？"（本质 = 校准问题 + 把责任交回。）
- **一定要索取回报**：任何让步都绑条件："我可以帮到这个价，条件是您这周下单 / 结一款定金。"**呼应第4节"每次让步换回条件"。**

**终局（收口与被砍）**
- **好人/坏人**：分工式谈判（一个强硬一个折中）只适合团队，单人销售借鉴的是"上面有领导可请示"的流程性折中，**不用来欺骗客户**。
- **蚕食**：主价谈定后，用"小项"补利润——"既然单价定了，这个 [配件/延长质保] 要不要一起带上，我可以给你打包价。"（呼应心理账户：付款后再加购更顺，influence.md 已证。）
- **让步模式**：幅度递减（10→6→4→2），越让越少 = 到底。参考第4节。
- **收回报价**：对方逼到临界，收回之前的让步——**使用前提（盲测整改）：仅当让步依据（配额/成本/汇率/船期）真实变化时使用，且必须如实说明原因并给替代方案**：`那个价我批不下来了，现在能给的是 X；或者量到 Y，我再帮您申请。`让步若并未真实收回，本条即触发虚假稀缺红线，作废；**熟客与长期合作客户禁用**。
- **留面子**：给台阶让他调整报价时不损失自尊——"我理解您有预算压力，那我们先看能不能把量或型号优化到您的数"。
- **起草合同 / 明确下一步**：谈拢立刻落到纸面（订单/合同/时间表），锁死。

**落地总则**：Dawson 的核心不是"斗狠"，而是**"谁更了解这场谈判的结构、谁就能主导节奏"**。所有这些"套路"都要建立在真实报价、真实成本、真实承诺的底线上，否则就是红线。

### 3.8 金牌业务谈判技巧组合（实战培训沉淀，经验型）

> 来自谈判培训课程提炼的"技巧组合"，特点是**两两成对、互补使用**，比单一招式更抗反击。属经验型，不是学术实证。

**谈判 8 步法**（顺序推进）：提出重要问题 → 专注争取认同 → 拉高双方期望 → 创造信任感受 → 用心聆听需求 → 经营伙伴关系 → 酝酿切身感受 → 精炼表达技巧。核心是"让客户自己被带动"，不是"吃掉对方"。

**7 个两两组合技巧**：
1. **激励 + 交心**：报价前先给激励（"这个方案能帮您…"），再交心（"我理解您这边压力在…"）——先点火，再共情。
2. **倾听 + 探索**：先真正听完（不打断），再用开放问题探索："您最在意的是价格，还是交付时间？"
3. **喂哺 + 搧风**：给足信息（喂哺）让他有依据，同时放大痛点（搧风）——"您现在的成本结构里，这块浪费每年占多少？"
4. **敲钟 + 畅议**：用事实敲醒（"这个节点不快定，您的排期就赶不上"），再畅快地讨论解法——先制造紧迫，再给出口。
5. **示弱 + 暂缓**：适当地"示弱"（"这个价我真得回去申请"）＋ 暂缓（"给我一天，我尽力"），给自己缓冲的谈判空间。
6. **守护 + 扎根**：守住底线（"I can't go below this"）＋ 扎根到价值（"因为这里面含认证和质保"）——守价时必须有理由支撑。
7. **让步 + 撤回**：小步让步，但每次有条件；必要时撤回之前的让步（参考 3.7"收回报价"），制造真实的时间压力。

**沟通谈判 9 大要项**（谈判全程的检查清单）：帮助顾客作决策、主动满足需求、过滤顾客的意见、给顾客扎实的信息、带着解决方案来、确认客户是否需要进一步理解、兑现承诺（说过必做到）、了解双方发展的关键、问题处理不马虎。

**顾问式销售 8 技**（一个会话内的表达节奏）：寒暄式提问 → 分享式交流 → 听问式沟通 → 数据式说明 → 教练式引导 → 动机式说服 → 方案式建议 → 行动式结语。→ 与前文 2.3 顾问式销售呼应：开头别急着卖，用"寒暄+倾听+教练式问"铺路，结尾落到"行动式结语"（明确下一步）。

**红线**：示弱/暂缓/暂缓撤回都是**姿态技巧**，必须建立在真实决策流程上；不能为制造紧迫撒谎（假倒计时、假审批）。

## 4 让步阶梯（Dawson 体系 + 通用规则）

**三条铁律**：
1. **让步幅度递减**：让的幅度越来越小（10 → 6 → 4 → 2），对方感知"到底了"。反着来（2→4→6→10）等于告诉他"还有空间"。
2. **每次让步都要换回条件**：让价必须绑条件——"这个价可以，条件是：数量加到 X / 定金 50% / 这周定下来"。**白让的价换不来忠诚**。
3. **不先亮底牌**：自己先报"最低价"，后面就只剩被砍。

**内贸/外贸通用的让步顺序建议（先让价值，后让价格）**：
1. 先让"软的"：免费样品运费抵扣、延长报价有效期、送一项小服务。
2. 再让"中等的"：运费分摊、交期承诺、包装升级。
3. 最后才让"硬的"：单价——而且必须换条件。

**让价话术**：
- `这个价格我需要老板批，但我可以帮你争取到 [X]，条件是这周五前定下来 + 定金 50%。`
- `单价我让不了 [X] 那么多，但我可以把 [运费/包装/账期] 这块帮你省出来——加起来你实际成本差不多。`

## 5 BATNA（最佳替代方案）—— 上桌前的底牌

**BATNA = 谈不成时你最好的退路**。谈判力 = 谁的 BATNA 更好，谁更不急。

**谈判前 Initial Assessment 三问**（借鉴 louisblythe/Sales-Skills pricing-negotiation，3 分钟过一遍）：
1. **Deal Context**：单子多大？谈到哪一步了？竞品态势？双方各有什么筹码？
2. **Pricing Situation**：对方提的哪种异议？价差多少？**真预算约束还是姿态**？推动谈判的是使用者还是采购部？
3. **Relationship**：新客户还是老客户？长期潜力多大？这个客户当参考案例值多少？走开的代价？

**业务员版 BATNA 检查表（报价前 5 分钟想一遍）**：
- 我这个客户如果不成交，下一个最好机会是什么？价值多大？
- 客户如果不买，他的替代方案是什么（别的供应商、自己解决、拖一拖）？——**他的 BATNA 比我好，就别硬谈价**。
- 我有没有"不成交也能获益"的退路（转介绍、做口碑、当渠道案例）？
- 谈不拢的合理收尾："这个价我们做不了，但如果未来量上去了，随时回来找我"——保住关系，等于保住未来 BATNA。

**ZOPA（可能成交区）**：我的底价 < 他的最高价，才有成交区。算出双方的区间再谈，谈不出成交区就礼貌结束，别硬磨。

## 6 战术共情与校准问题（Chris Voss 体系，谈判卡壳/情绪化时用）

- **镜像（Mirroring）**：重复对方最后几个词，让他多说。"你说'价格太高'——高在哪个部分？"
- **标注（Labeling）**：说出对方情绪，给安全感。"听起来你觉得这个价不太合理。"（说完停，沉默等对方反应——**沉默是你的武器**）
- **校准问题（Calibrated Questions）**：用 What/How 开头，把责任移给对方，避免"能不能/是不是"引发对抗：
  - `How am I supposed to do that?`（把难题还给他）
  - `What would it take to make this work?`（What would it take 是万能推进句）
  - `How should we proceed?`
- **"No"的力量**：让客户说"不"，反而打开对话。`这个方案现在做，你觉得哪里行不通？`（他答"行不通的地方"，就是真实障碍，比逼他点头有用。）
- **阿克曼议价（Ackerman）**：目标价 → 目标价 65% 开口 → 85% → 95% → 100%，最后一步给出精确数字（不是整数）："我最后能给到 4,835，这是我能到的极限。"（精确数字显得计算过、可信）

**禁忌**：战术共情不是操纵——标注情绪必须真实，否则是"表演式共情"，客户一次就识破。

## 7 常见误区

1. **把压价当敌意**：压价常常是采购的流程动作（本技能信号词典已讲）。真正没预算的人不问你交期。
2. **赢了价格输了关系**：把客户砍到你的底价并炫耀"我守住了"，等于告诉他没有下次。
3. **让步太快**：一次让到位 = 让他觉得还有空间。让步要挤牙膏式。
4. **不会说"不"**：`这个价做不了` 说得干脆，比绕来绕去最后给低价更受尊重。**尊严对等是专业的一部分。**
5. **忽视 BATNA**：没想清楚退路就上桌，容易在压力下白让。
