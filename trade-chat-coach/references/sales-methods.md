# 销售方法论：选对打法，再开口

配套 `SKILL.md` 的 Step 3–5 使用。**判断（他是不是真要买）和推进（怎么把他往下一级带）是两件事**——判断用信号词典，推进用这里的方法论。

## 0 怎么用这份文件

- 判断完客户类型后，来这里**选一套打法**，不要每次凭手感发挥。
- 快速路由：小单/零售 → SPIN 简化版；复杂 B2B/教育客户 → Challenger；中单/标准化 → 顾问式；大客户/多角色决策 → Miller Heiman + MEDDIC；内贸/销售团队管理视角 → 阿里铁军；出口/项目型 → 华为 LTC 思路。
- 每节都有"迁移到聊天跟进"的具体动作，直接取用。

## 1 方法总览表

| 方法 | 内核一句话 | 适合 | 不适合 | 证据等级 |
|---|---|---|---|---|
| SPIN Selling | 用 Situation→Problem→Implication→Need-payoff 四类问题把"隐含需求"变成"明确需求" | 复杂/高价值、需要挖掘需求的单 | 标准化快单、价格敏感型零售 | A（Huthwaite 12 年研究，但样本数字需核对） |
| Challenger Sale | 用商业洞察"教导"客户，重构他的看法，再"定制+掌控" | 需教育市场的复杂 B2B | 产品平庸、缺乏赋能素材的团队 | B（CEB 研究原始数据未公开；A 级只有其存在性） |
| 顾问式/解决方案销售 | 卖的是"解决客户问题的方案"，不是产品参数 | 解决方案型、按项目卖的生意 | 纯标准化标品快单 | 经验型为主 |
| Miller Heiman 大客户 | 用"权力金字塔"看清决策链，蓝表红表管覆盖 | 大客户、多角色决策、长周期 | 小客户、个人决策 | 经验型为主（有方法论体系） |
| MEDDIC | 六项资格审核：M-E-D-D-I-C，别在假单上浪费时间 | B2B 大单资格评估 | 单角色快单 | 经验型（Salesforce 生态普及） |
| 阿里铁军 | 量变到质变 + 流程化拜访 + 目标管理 | 内贸销售团队、电话/陌拜 | 复杂咨询型销售 | 经验型（贺学友等著作） |
| 华为 LTC/铁三角 | 客户经理-方案-交付铁三角协同，端到端管商机 | 项目型/政企/大客户 | 单人小单 | B（咨询公司转述，自报数据前后矛盾） |

## 2 逐个方法

### 2.1 SPIN Selling（尼尔·雷克汉姆，1988）

**内核**：Huthwaite 为期 12 年、耗资约 100 万美元的研究（出版方层面可追溯，A 级）。核心发现：**收场技巧（close）在小额销售有效，在大额销售失效**——大单赢家靠的是提问质量，不是逼单。

四类问题，按顺序：
- **S Situation 背景问题**："你们现在用的什么方案？"——少问，问多了像审问。
- **P Problem 难题问题**："现在这套哪里不满意？"——找隐含需求。
- **I Implication 暗示问题**："这个问题不解决，会影响到什么？"——把代价放大、量化（损失厌恶的入口）。
- **N Need-payoff 需求-收益问题**："如果解决了，你们能省多少/快多少？"——让客户自己说出价值，而不是你替他说。

**迁移到聊天跟进**：
- 客户只问价 → 先用 P 问出他现在的痛点，再报"带方案的价"。
- 客户嫌贵 → 回到 I：问"现在这套出问题的成本是多少"，把价格锚到"不作为的代价"上。
- 禁止：对每个客户背一遍四类问题清单。S 类问题控制在 1-2 个。

**数据**：网上流传"35,000 次销售拜访""10 万+ 访谈"等具体数字，**本次调研未核到一手出处，列为待核实，不要当事实引用**（A 级可确认的只有"12 年、约 100 万美元"）。

### 2.2 The Challenger Sale（Matthew Dixon & Brent Adamson，2011）

**内核**：CEB 对 6,000+ 销售代表的研究（B 级，原始报告未公开、学术论文已指出 "not obtainable for reference"）。主张"关系型销售已死"：高绩效者多为"挑战者"，用商业洞察重构客户的看法，而不是附和。

三步（Teach-Tailor-Take Control）：
- **Teach 教导**：教客户一个他自己没意识到的问题或趋势。"你知道你们这种产线的隐性成本其实在 X 吗？"
- **Tailor 定制**：把洞察接到他自己的业务上。"对你们这种月产能 3 万台的厂，这个问题的代价是 Y。"
- **Take Control 掌控**：主导下一步。"所以我的建议是：先做一个两周的试点，用数据说话。"

**迁移到聊天跟进**：
- 客户一直说"我们挺好的/没什么需求" → 给一条真实洞察（行业数据、竞品动态、新合规要求），比十个产品卖点有效。
- **注意反噬**：把"掌控"执行成"压客户"，是最大的落地失败模式。洞察必须真实，编造即翻车。

**学术级补充（A 级，Waugh 2024，20 名跨国公司高管访谈）**：单次交易层面，预先关系不是必要条件，知识与可信度更关键；但**长期重复购买必须靠信任关系维持**。→ 对新客户先亮洞见建立可信度，对老客户维护信任比持续推销更重要。

### 2.3 顾问式/解决方案销售（Michael Bosworth 等）

**内核**：先诊断再开方。"卖产品"的姿势是背参数；"顾问式"的姿势是先让他承认问题，再让方案自然落位。三个步骤：**确认问题 → 量化代价 → 呈现方案**。

**迁移到聊天跟进**：客户要报价单 → 先问"要解决什么问题"，拿到答案再给方案式报价（不是价目表）。这就是本技能"报价换信息"原则的理论来源。

### 2.4 Miller Heiman Strategic Selling（大客户销售）

**内核**：大单不是赢在关系，是赢在**看清决策链并管理每个角色**。
- **权力金字塔**：经济买家（批钱）> 使用者买家（天天用）> 技术买家（把参数关）> **教练（Coach，给你内部信息的人）**。
- 蓝表管"销售策略"，红表管"客户方角色"。

**迁移到聊天跟进**：客户说"我回去考虑一下" → 不要干等。问"除了你，还有谁参与决定？他更关心价格还是交付？"——这就是本技能"需求翻译第四层：决策链"的操作化。答不上来，说明你在跟一个没有决定权的人。

### 2.5 MEDDIC（Dick Dunne）

**内核**：六项资格审核——**M**etrics（可量化收益）、**E**conomic buyer（经济买家）、**D**ecision criteria（决策标准）、**D**ecision process（决策流程）、**I**dentify pain（痛点）、**C**hampion（内部教练）。
**本质**：一张资格审核表，不是需求创造机。用途是**别在假单上烧时间**——和本技能的 A/B/C 客户分层是一回事。

**迁移到聊天跟进**：跟进两周还没有经济买家/没有量化收益/没有内部教练，这个"单"就只是"话题"。该降级就降级。

### 2.6 阿里铁军（贺学友《销售铁军》《销售冠军是如何炼成的》）

**内核**：销售是"量变到质变"的体力活 + 流程化 + 目标管理。中供铁军的基本功：拜访量、话术标准化、客户分类、复盘。

**迁移到聊天跟进**：
- 把跟进做成**流程**而不是看心情：每天固定时间回消息、每次跟进带新信息、每周复盘客户分层。
- "量变到质变"对应的管理动作：低转化时先检查拜访量/触达量，再谈话术。

### 2.7 华为 LTC / 铁三角

**内核**：客户经理（AR，懂客户）＋ 方案经理（SR，懂方案）＋ 交付经理（FR，懂交付）三人协同；从线索到回款端到端管理。
**迁移到聊天跟进**：单子进入技术细节或交付风险阶段时，**把技术/交付的人拉进对话**（哪怕拉个群），而不是你一个人不懂装懂。客户感知的"靠谱"很大程度来自"有人真的懂"。

### 2.8 GROW 成交模型（教练式，先问目的再推方案）

**内核**：一个大单成交=客户"自己要的"。GROW 不是逼单，是用**采访式提问**让客户自己把"想要的未来"和"现在的障碍"说清楚，再让方案自然落位。适合**高价值、有决策权、愿意聊开的客户**（保险/大件/顾问型销售尤佳）；不适合标准化快单的轻量客户。

- **G Goal 目标**：先问"目的/最在乎什么"，**不要一上来卖 feature**。例（保险，愿景式提问，盲测整改后）：`您最想给家人什么样的保障？希望将来他们提起您时，最先想到什么？`——把"买"绑定到一个他在乎的目的上（他会愿意为"完成这个目的"付高价）。注意：忌讳式恐惧开场（"如果发生意外……"）放信任建立后再以"帮您做规划"的口吻引入，且该问法更偏 R 步，G 步始终从愿景问起。
- **R Reality 现状**：问出"现状与目标的 gap"和"障碍"。`要达到这个目标，您现在遇到了什么？`——采访式，让他自己说出现状，别替他说。
- **O Option 方案**：`有哪些方法能让您靠近目标？`先让他列（自己努力/资源/……），再自然提出"其实我这边的方案也可以作为一个选项"——**基于他的问题给方案，方案对他才有价值**。
- **W Willingness 意愿**：`在这几个方案里，您最愿意执行哪一个？想多快开始？`——让他自己选、自己定时间，成交是他主动的。

**迁移到聊天跟进**：客户嫌贵 / 犹豫时，回到 G：`您当初想做这件事，最想解决的是什么？`——把他拉回"目的"，而不是在价格上硬磨（= SPIN 的 I + N 的教练版）。
**注意**：每一步都要"耐心采访"而不是"销售味太重"——对方不愿打开心扉时，你挖不到真目的。他说"再等等"，先别急着推，问出卡住的 G 是什么。

### 2.9 RAIN 全流程销售模式（迈克·舒尔茨 / 约翰·杜尔，RAIN Group）

**内核**：一次强力销售对话 = 四个阶段按序走完。来源：作者几十年销售经验 + 对世界500强企业销售组织领导者的访谈（经验型；微信读书旧版 80.6 分 / 174 人评，新版评分不足）。

四阶段（对话流程版，与 SPIN 的对应关系见括号）：
- **R Rapport 寒暄**：获得初步好感、强化信任。不是闲聊客套，而是让对方感到"你懂他的处境"（= eq-communication 的信任建立；书内划线最多的一句："没人在意你知道多少，除非人们知道你对他们有多在意"）。
- **A&I Aspirations & Afflictions 渴望和痛点**：发现"他想要达成什么"（渴望）和"什么在阻碍他"（痛点）（= SPIN 的 S+P，但强调两个都要问——很多业务员只挖痛点不问渴望）。
- **I Impact 冲击力**：引导客户自己意识到问题的严重性——不替他算账，问出代价（= SPIN 的 I 暗示问题）。
- **NR New Reality 新现实**：让客户透彻理解"跟他合作后的新状态"——用具体的未来画面呈现价值（= SPIN 的 N + 方案呈现）。

**迁移到聊天跟进**：
- 开场别急着报价：先 Rapport（一条有价值的信息）→ A&I（`您希望这个项目最终达到什么效果？现在卡在哪？`）→ Impact（`这个卡点不解决，会影响哪些环节？`）→ New Reality（`按这个方案走，三个月后您的产线是……`）。
- 判别单子真假：四阶段里客户只在 R 层寒暄、从不下探 A&I 的，多是比价客（对应 signals.md 判断）。
- 红线：Rapport 不能滑向油腻恭维（zh-playbook 禁句）；Impact 用真实代价，不制造假恐惧。

**书内另一条高划线**（52 人）："如果想法改变，态度就会改变；如果态度改变，行为就会改变……"——本技能用法：**先改客户对问题的认知（Teach/Impact），成交态度会自己变**，比反复催单有效。

## 3 可直接使用的问题库（按方法归类）

**SPIN 版（挖掘需求）**
- S：`你们现在主要用哪个规格？`（限 1-2 个）
- P：`现在这套最不满意的是什么？` / `What's not working with your current supplier?`
- I：`这个问题每次发生，你们要额外花多少时间/成本？` / `If the delivery is late, what does that cost you?`
- N：`如果一周内能到货，你们的项目能往前赶多少？` / `How much would it help if this were solved before the deadline?`

**Challenger 版（重构认知）**
- `你们行业的合规要求下个月要变了，目前市面上的方案里，大部分都不满足——你们现在的选型标准需要加上这一条。`（换成真实事实）
- `你们这种规模的厂，隐性成本一般不在单价里，而在停机/退货/翻工——你想看一组同行的数据吗？`

**MEDDIC 版（资格审核）**
- `除了你，谁参与最终决定？他主要看价格还是交付？`
- `这笔采购你今年有预算吗？大概什么量级？`
- `这个项目做成什么样，你内部会觉得是"成功"？`

**顾问式版（诊断再开方）**
- `要解决什么问题？ / What problem are you trying to solve with this order?`
- `现在的方案哪里不合适？ / What's not working today?`

## 5 常见误区与被夸大的说法

1. **"关系型销售已死"被过度简化**：对单次交易成立（洞见>关系），对长期复购不成立（信任>推销）。两句话在不同阶段都对。
2. **所有框架都有事后归因偏差**：它们研究的是赢了的单子；"符合框架但客户就是不买"的样本很少被同等研究。
3. **大部分数据来自卖方生态**（Huthwaite、Challenger Inc.、咨询公司），利益相关；只有 Rackham 研究在出版方层面留下了可追溯的研究规模记载。
4. **框架救不了产品与市场匹配**：产品不行，再好的话术也是加速失败。
5. **中国大客户销售的实证研究基本缺位**：网络流传的"关系/饭局/送礼"话术没有可靠研究支撑，且商业贿赂有明确法律风险。"关系"可迁移的部分是**信任建立、信息获取、决策链理解**，不是利益输送。
