# 高情商沟通话术库（按情境分类 · 中文场景）

> **记号**：📗 = B站原始语料（可追溯，C 级平台实证）｜🏆 = 高赞语料（注明赞数）｜📘 = 方法论提炼（非实证）｜👍N = 该条点赞数

> **定位**：本文件是 `eq-communication.md` 的**情境扩展版**——那份讲"高情商怎么转译成动作"，这份给**按场景可直接抄的原话**。
> **核心认知**：高情商 ≠ 会说漂亮话，高情商 = **让对方感觉自己被看见、被尊重、不被为难**。
> **纪律**：任何话术发出前，先过第 13 节的五遍自检。**实时模式（"快帮我回"）下压缩为第 1 遍（语气）+ 第 5 遍（边界）两遍即可。**

---

## 0 三条底层原则（所有情境通用）

| 原则 | 含义 | 反面 |
|---|---|---|
| **先接后转** | 先承接对方情绪，再转到你要说的事 | 一上来就讲道理/辩解 |
| **给台阶** | 永远让对方有体面的退路 | 把人逼到墙角 |
| **少而准** | 一句到点，胜过十句客套 | 长篇解释、反复保证 |

> 📗 语料印证（大客户销售，👍183）：**「做销售特别是陌拜，永远别让任何一方陷入尴尬的境地。」**
> 这句话适用于**所有**沟通场景，不只是陌拜。

## 1 开口与破冰

### 1.1 第一次加微信 / 首次联系
**结构：我是谁 + 为什么是你 + 不打扰承诺**
- 「X总您好，我是××公司的××。**打扰您 1 分钟**——之前展会/李总那边提到过您，说您这边在这方面经验多，想跟您认识一下。」
- 「我是做××的，**不是来推销的**，就是先认识一下，后面有相关信息我发给您，您用得上就看。」
- 「加您主要是想**把行业里的一些资料同步给您**，不用回我。」

❌ 别这么发：「您好，我们是专业提供××解决方案的供应商，希望能有机会合作。」（模板味重，秒被忽略）

### 1.2 陌生电话开场（8 秒内说完）
- 「X总您好，**就占用您 2 分钟**。我是××的××，**关于您上次提的那个问题，我们这边有个新解法**，想跟您对一下。」
- 「不方便的话我改天再打，**您说个时间**。」

### 1.3 冷启动找话题（避免查户口式提问）
- 从**对方的地盘**找：「看您朋友圈刚去了××，那边怎么样？」（具体、真诚，不是"最近忙吗"）
- 从**共同语境**找：「您也是做××的，**今年这个行情您那边感受怎么样？**」

## 2 回应与倾听（让客户愿意说真话）

> 📗 语料印证（谈判笔记，👍698 第 7 条）：**「做好的聆听者。做好聆听就越了解对方，谈判越有利。每个人的需求是不同的。」**

**三个让对话继续的动作：**
| 动作 | 话术 |
|---|---|
| **复述确认** | 「我理解一下——您是说**A 不是问题，卡在 B**，对吗？」 |
| **追问细节**（显得在意） | 「这个'麻烦'，**具体是哪一步最费劲？**」 |
| **不急着解决** | 📘「客户问题不要马上解答，**要深挖深层需求**。」→「嗯，那这种情况一般多久出现一次？」 |

**沉默的用法**：客户说完，**停 2 秒再答**。停顿会让对方补充更多（谈判中的"沉默压力"）。

❌ 别做：抢话、马上给方案、把客户的话当"问题"来修。

## 3 赞美（真诚不油腻）

**公式：具体细节 + 你的真实感受 + 不索取**
- ✅ 「您刚才那句'先活下来再谈规模'，**我觉得特别实在**。很多人上来就讲增长。」（具体到某句话）
- ✅ 「您这个方案里把**售后成本单列**，说明您是真懂现场的人。」（细节证明观察）
- ❌ 「X总您真厉害/年轻有为/格局大。」（空洞、模板）
- ❌ 「您这气质一看就是做大事的。」（谄媚）

> 📗 语料印证（谈判笔记，👍698 第 4 条）：**「尊重对方，故意恭维对方。比如对替补人员，一定要让对方感受到尊重，不能让替补感受到'不被重视'。」**
> 延伸：**对"非决策人"（前台、助理、基层对接人）的尊重，回报率最高**——他们常常是信息源与内部推动者。

## 4 共情（客户抱怨 / 发火 / 遇到麻烦）

> 📗 语料印证（B站，AI课代表总结）：**「本能辩驳只会切断需求洞察。正确路径始于共情确认，继而用开放式问题探索。」**

**四步：接情绪 → 认事实 → 问细节 → 给动作**
1. **接情绪**：「这事换成我，我也上火。」
2. **认事实**（不推责）：「确实是我们这边没跟上，**这个不赖您**。」
3. **问细节**：「您先跟我说一下，**具体是哪一批、什么时候的事**？」
4. **给动作**：「我今天就跟到解决为止，**X 点前给您一个明确说法**。」

**不同情绪的分支话术**
| 客户状态 | 话术 |
|---|---|
| 发火 | 「您先别急，**这事我接住了**。您骂我两句都行，但咱先把事解决了。」 |
| 抱怨（对行业/公司） | 「您说的这个确实是普遍现象。**您那边最难受的是哪一块？**」 |
| 沮丧（做不成） | 「这次没成不全是您的问题。**咱们看看哪一步还能补**。」 |
| 焦虑（怕耽误） | 「我理解您赶时间。**我把最坏的情况先跟您说明白**，再讲怎么避免。」 |

❌ 别做：抢着解释、说"这是规定"、说"别人都没问题"（= 都是你的错）。

## 5 拒绝（不伤关系）

**结构：理解 + 明确不（别含糊） + 给替代 + 留口子**
- 「这事我真做不到。**但我不想含糊您**——不是不愿意，是确实超出我的范围。」
- 「这个价我确实给不了。**我能给的是：质保加一年 + 优先排期。**」
- 「您这个要求我记下了，**下次有政策我第一个告诉您**。」
- 「**这次真不行**。您要是不着急，三个月后可能有变化，我到时提醒您。」

> 关键：**拒绝要快、要明确、要给替代**。含糊拖延 = 更伤关系。

---

## 6 道歉（危机处理）

**结构：认错具体 + 不找借口 + 给补偿 + 说改进**
- 「这次延期是我们的问题，**不用您催，是我们没安排好**。」
- 「我不解释原因，**先说怎么补救**：今天发加急、运费我们出、再补一份备件。」
- 「这种事不会再有第二次，**我把它写进流程了**，下次您盯我。」

❌ 别做：说"主要是物流/工厂/天气"（听起来像推责）、说"下次一定注意"（空头承诺）、反复道歉不给方案。

## 7 化解尴尬

| 情形 | 话术 |
|---|---|
| **冷场** | 「说到这个我想起来了——」/ 直接换话题：「对了，您那边最近……」 |
| **说错话** | 「这句我说得不合适，**收回**。我的意思是……」 |
| **被拆穿（吹过头）** | 别硬撑：「**这块我确实不熟，我回去问准了再答您**，不瞎说。」（诚实反而加分） |
| **被拒绝/被赶** | 「理解，那我不打扰。**资料放这儿，您有空看一眼就行。**」 |
| **对方记错/弄错** | 「可能是我们沟通的时候没说清，**我再跟您对一遍**。」（不纠正"你错了"） |
| **第三方在场为难** | 「这个咱们私下再聊，**今天先不占大家时间**。」 |

> 📗 语料印证（陌拜案例，👍183）：**「陌拜时，扣门是最关键的。……这个时候要做的是推——留个印象，先主动退出来，不要让别人疑虑加深。」**
> 同理：**看穿对方在试探时，最体面的回应是主动退场，不是拆穿。**

## 8 催回复 / 已读不回

**核心：每次触达都带"新信息"，不做"在吗"式打扰**

| 轮次 | 话术 |
|---|---|
| 第 1 次（轻） | 「X总，看到个您行业相关的政策，**转您看下，不用回**。」 |
| 第 2 次（给理由） | 「上次您问的交付时间，我核实了是 X 号。**这个节点您那边来得及吗？**」 |
| 第 3 次（降门槛） | 「**就一个问题**：这事您是暂时搁置，还是这季度要推？我好安排后面的节奏。」 |
| 第 4 次（给退路） | 「不打扰您了。**后面有需要随时招呼我。**」（体面收尾，别纠缠） |

❌ 别发：「在吗」「考虑得怎么样了」「我们真的很重视您」。

## 9 传递坏消息（涨价 / 延期 / 没成）

**结构：提前 + 直说 + 影响 + 补救 + 给选择**
- **涨价**：「跟您提前说一声，**下月起这个型号涨 5%**。您要是有计划，这个月定能锁老价。」
- **延期**：「有个不好的消息，**交付要往后推 5 天**。原因我不绕：上游出了问题。补救方案是分两批发，先到的那批够您撑住。」
- **没成（投标失败）**：「这次没中。**我复盘了一下，主要是资质那块差一档**，跟您说一下，下次咱一起补上。」

> 要点：**坏消息越早说越像自己人，越晚说越像隐瞒。**

---

## 10 求人办事（要转介绍 / 要资料 / 要帮忙）

**结构：说清请求 + 给对方低成本的选项 + 给对方好处或体面**
- 「您同行要是有人遇到类似问题，**方便帮我引荐一句吗**？不用您费心，我加他微信就行。」
- 「想请您帮个小忙——**能不能帮我看一眼这个方案，哪里不专业您直说**？」（给对方"专家"的位置）
- 「想请您**指点一下这块**——方便的话我带着资料过去，占您十几分钟，不耽误您正事。」
- 「这次麻烦您了，**下次您那边有事，我一定尽力。**」（给回报预期，但不功利地提条件）

> 📌 商务往来须符合公司政策与当地法律；**不得以礼品/宴请换取采购决策**。

## 11 分寸感与边界（什么时候该闭嘴）

- ✅ 客户说"我考虑一下" → **别追问为什么**，给台阶，约下次
- ✅ 客户在忙 → **一句话说清来意，主动收线**：「您先忙，我发文字给您。」
- ✅ 涉及对方内部人事/竞品内部信息 → **不打听、不评价**
- ✅ 客户明显敷衍 3 次以上 → **降级为长期培育**，别再高频触达
- 🚫 客户没问就长篇解释
- 🚫 半夜/周末非紧急事项发消息（除非对方习惯如此）
- 🚫 在对方群里公开施压

## 12 油腻话术黑名单（这些话别用）

| 油腻话术 | 问题 |
|---|---|
| 「在吗？」 | 零信息，制造焦虑 |
| 「亲，在的哦~」 | 客服腔，不专业 |
| 「咱们是朋友，价格好说」 | 廉价，且后续难守价 |
| 「我给您申请个特价」（其实本来就能给） | 一旦被识破，信任归零 |
| 「这个价格已经是最低了，我骗您干嘛」 | 越强调越可疑 |
| 「您不懂，听我说」 | 居高临下 |
| 「别人都能接受，就您……」 | 道德绑架 |
| 过度表情包 / 频繁"哈哈哈" | 不严肃，降低专业感 |

> 📗 语料印证（销售话术评论区，👍13）：**「恭维讨好、利诱铺路、没脸没皮……开始这些可以欺骗淳朴，后来这些导致信任缺失，如今信任缺失越来越严重的时代，这些也越来越不好用了。」**

## 13 发出前五遍自检（照着过）

1. **语气**：读一遍，像不像"客服模板"？像就改。
2. **环境**：对方现在方便看长消息吗？不方便就只说一句。
3. **方式**：这件事该微信说、电话说，还是当面说？
4. **逻辑**：有没有漏洞？会不会被一句话顶回来？
5. **边界**：有没有让对方为难？有没有越界打探或施压？

> 五遍都过 → 发。任一遍不过 → 改到过为止。
